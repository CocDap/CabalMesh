# P3 — Bring Your Own Key (OpenAI-compatible) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each device chooses its own model endpoint (base URL, model name, API key) from the Profile screen, and every AI call in the app goes through one OpenAI-compatible client.

**Architecture:** `llm_config.rs` replaces `ollama_config.rs`: base URL, model and preset live in a plain JSON store; the API key lives in its own vault file with the same key provider as the wallet. `llm_client.rs` speaks `/v1/chat/completions` with optional JSON mode and tools, and a `LlmBudget` caps calls per hour. `intent_chat.rs` and `negotiation.rs` move off Ollama's `/api/generate`.

**Tech Stack:** Rust, reqwest 0.13, `cabal-store`, `cabal-vault`; React 19.

**Spec:** `docs/superpowers/specs/2026-11-04-near-migration-design.md` (P3 section).

## Global Constraints

- OpenAI-compatible only: `POST {base_url}/chat/completions`, `Authorization: Bearer <key>` sent only when a key is set. No environment variables.
- Presets, verbatim:
  - `near-ai` — `https://cloud-api.near.ai/v1`, model blank (user picks)
  - `ollama-local` — `http://localhost:11434/v1` (Android emulator: `http://10.0.2.2:11434/v1`), model `llama3.1:8b`
  - `openrouter` — `https://openrouter.ai/api/v1`, model blank
  - `custom` — everything typed by the user
- Default on first run is `ollama-local` with `llama3.1:8b`, so existing installs keep today's behaviour.
- The API key is never logged, never returned to the webview (only `hasApiKey: bool`), never placed in a mesh payload.
- Call budget default **30 per hour**, editable in Profile, range 1–600.
- New Tauri commands follow the five-place registration rule in the P1 plan, then `npm run bindings`.

## Review Focus

1. **User pastes a base URL with a trailing slash or `/chat/completions` already on it.** Expect normalization to the `/v1` root, not `…/v1/chat/completions/chat/completions`. Test owned by Task 1.
2. **Provider returns JSON wrapped in prose or code fences despite JSON mode.** Expect `llm_json::extract_json_object` to still recover it. Test owned by Task 2.
3. **Provider rejects `response_format` (HTTP 400).** Expect one retry without it, then the same `llm_json` recovery. Test owned by Task 2.
4. **Key set, then preset switched.** Expect the key kept per preset, not leaked to a different host. Test owned by Task 1.
5. **Budget exhausted mid-negotiation.** Expect the code-only fallback price path (`negotiation.rs` `deterministic_settlement`, method `"fallback"`) rather than a stalled deal. Test owned by Task 5.
